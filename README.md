Yes, AI was involved. (Tested and Developed on CachyOS)
But I couldn't find any good alternatives so I made my own!
## Authors

- [@jj-wonderhoy](https://www.github.com/jj-wonderhoy)

## Installation



```bash
git clone https://github.com/jj-wonderhoy/JJ-TTS
cd JJ-TTS
./install.sh
```
    
## Features

- Piper, Kokoro, and GTTS Voice Engines
- Piper Voice Installer
- VRChat Chatbox Integration
- Phrase Pre-setting
- Quick Type (CTRL ALT SPACE or Bind jj-tts --quick in your DE/WM)
- GTK4 (Matches System Colors!)
